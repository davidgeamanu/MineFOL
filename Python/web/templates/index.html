    How to play
    • Flag every mine. Each clue is a true statement about the board; a page icon marks the cells whose clue you have read.
    • Move with WASD / arrow keys, or click a cell next to you. Risky moves are allowed.
    • Switch to Flag to mark a mine; a wrong flag ends the game.
    • Drag clues in the knowledge base by their handle to keep the useful ones together. Reset order puts them back.
    • Show safe moves: Mace4 finds the neighbours that are provably safe. Show proof asks Prover9 which clues prove it.
    • Show forced mines: Mace4 finds the cells that must be mines.
